## Isi Tugas

Membuat halaman **Curriculum Vitae (CV)** menggunakan HTML dan CSS dengan menerapkan berbagai property CSS, 4 format warna, serta membuat mini style guide.

## Source Code

### HTML

File `Tugas3.html` digunakan untuk membuat struktur halaman Curriculum Vitae. Di dalamnya terdapat bagian header, foto profil, nama, profesi, profil, data diri, pendidikan, keahlian, kontak, dan footer.

### CSS

File `Style.css` digunakan untuk mengatur tampilan halaman seperti font, warna background, ukuran tulisan, jarak antar bagian, bentuk foto profil, border, gradient, link, footer, serta tampilan responsive untuk perangkat mobile.

## Mini Style Guide

### Font

**Font utama:** Arial  
**Font alternatif:** Helvetica, sans-serif  
**Font Heading:** Georgia, "Times New Roman", serif

### Warna

**Background:** `#faf8f8`  
**Header Gradient:** `#A3C9F0` dan `#FC84F2`  
**Warna Heading:** `hsl(202, 60%, 49%)`  
**Warna Border Heading:** `#ac2a78`  
**Warna Teks:** `#000000`

### Ukuran Heading

**H1:** 40px  
**H2:** 23px  
**Paragraph:** 18px

### Line Height

**Body:** 1.7  
**Paragraph:** 1.7  
**List:** 1.8

## Ringkasan dan Kesimpulan

Pada tugas ini saya membuat sebuah halaman Curriculum Vitae menggunakan HTML dan CSS. Halaman CV berisi beberapa informasi seperti profil, data diri, pendidikan, keahlian, kontak, dan footer. HTML digunakan untuk membuat struktur dan isi halaman, sedangkan CSS digunakan untuk mengatur tampilan agar lebih rapi, menarik, dan mudah dibaca. Pada tugas ini diterapkan berbagai property CSS seperti background-color, padding, text-align, width, height, border, color, font-size, border-bottom, dan line-height. Selain itu, digunakan empat format warna yaitu HEX, RGB, RGBA, dan HSL. Saya juga menggunakan dua jenis font, yaitu Arial sebagai font utama dan Georgia untuk bagian heading. Tampilan header dan footer menggunakan gradient dengan kombinasi warna biru dan pink. Website juga dilengkapi dengan responsive design menggunakan media query sehingga ukuran foto, teks, dan konten dapat menyesuaikan ketika dibuka pada perangkat mobile. Dari tugas ini saya menjadi lebih memahami penggunaan HTML dan CSS serta cara mengatur tampilan website agar dapat digunakan pada ukuran layar desktop maupun mobile.
